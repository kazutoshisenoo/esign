# AuraSign - 高級電子署名サービス

AuraSign は、PDFドキュメントをアップロードし、直感的なドラッグ＆ドロップで署名フィールドを配置、受信者のメールアドレス検証とワンタイムパスワード (OTP) を経て、セキュアにPDFへ署名を合成できる次世代電子署名プラットフォームです。

Apple, Stripe, Linear, Vercel のようなシンプルで高級感のあるUI/UXデザインを追求し、ダークモードやアクセシビリティにも考慮されています。

---

## 🚀 主要機能

### 1. PDFアップロード
- ドラッグ＆ドロップによる直感的なPDF読み込み。
- 複数ページ対応＆サムネイルリストによる容易なページ切り替え。
- アップロード不要で即座に動作検証できる「デモ用PDF自動生成」機能（開発・検証用）。

### 2. PDFエディタ（編集画面）
- PDF上に各種フィールド（署名欄、日付、氏名、会社名、フリーテキスト、チェックボックス）をマウスクリックで配置。
- ドラッグ移動、および右下のサイズハンドルによる無段階リサイズ。
- すべての位置およびサイズは `%` (パーセンテージ) で管理され、ズームやレスポンシブな画面リサイズでも常に相対位置を保持。

### 3. セキュアな署名依頼
- 送信者は相手の名前とメールアドレスを入力し、送信。
- 固有のランダムトークンURL（署名依頼リンク）を生成。

### 4. 受信者の署名入力
- 署名依頼リンクへのアクセス時、メールアドレスの入力とワンタイムパスワード (OTP: デモ用コード `123456`) による本人確認。
- 3つの署名スタイル：
  - **手書き**: マウスやタッチ操作で直感的に署名を作成。
  - **フォント署名**: キーボードで入力した名前を筆記体などの美しいフォントスタイルに変換。
  - **画像アップロード**: スキャンした署名印影などの画像（透過背景推奨）をアップロード。
- 署名完了後、`pdf-lib` によりクライアントサイドでPDF上の該当座標に署名画像・入力テキストを完全に埋め込み（マージ）。

### 5. セキュリティと監査
- **監査ログの自動生成**: IPアドレス、タイムスタンプ、ユーザーエージェント、および認証方式を監査ログデータとしてドキュメントに紐付け。
- **改ざん防止**: 署名確定後のドキュメントは更新不可。
- **監査証明**: ダウンロード可能な署名済みPDFの配布。

## 🛠️ 技術構成

- **Frontend**: React 19, TypeScript, Vite 8, Tailwind CSS v4 (プラグイン統合版)
- **PDF レンダリング**: `pdfjs-dist` (CDN worker 使用によるViteビルドトラブル防止)
- **PDF 合成**: `pdf-lib` (クライアントサイドでのセキュアな座標マージ)
- **アイコン**: `lucide-react`
- **Backend (スキーマ設計済)**: Supabase Auth, PostgreSQL, Supabase Storage

## 💻 ローカル開発手順

### 環境構築と起動

1. **フロントエンドディレクトリに移動**
   ```bash
   cd frontend
   ```

2. **依存関係のインストール**
   ```bash
   npm install
   ```

3. **ローカル開発サーバーの起動**
   ```bash
   npm run dev
   ```

4. **プロダクションビルド**
   ```bash
   npm run build
   ```

## 🛡️ セキュリティ設計詳細

### データベースセキュリティ (Row Level Security - RLS)
`backend/migrations/` にある SQL スキーマでは、PostgreSQL の行レベルセキュリティを有効化しています：
- **`profiles` / `documents` / `document_signers`**: 送信者自身（`auth.uid() = owner_id`）のみが自身のドキュメントや署名者の管理・閲覧が可能。
- **`signature_fields`**: 送信者は全操作、署名受信者は「トークン経由」で自身が割り当てられたフィールドのみ読み取りおよび書き込み（UPDATE）可能。また、ドキュメントの status が `'completed'` (完了) になった後は、RLS ポリシーにより署名者による再編集・更新を自動的に禁止。
- **`audit_logs`**: INSERT (作成) のみシステムおよび特定のEdge Functionから許可され、いかなるユーザーも UPDATE (編集) または DELETE (削除) することはできません。
